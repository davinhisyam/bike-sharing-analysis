# Bike Sharing Data Analysis Dashboard 

## Deskripsi
Proyek ini adalah analisis data pada "Bike Sharing Dataset" untuk mencari pola penyewaan sepeda berdasarkan kondisi cuaca, musim, dan waktu operasional (jam).

## Struktur Folder
- `/data`: Berisi dataset mentah (day.csv & hour.csv).
- `/dashboard`: Berisi file dashboard.py dan main_data.csv yang sudah bersih.
- `notebook.ipynb`: File analisis data lengkap dari gathering hingga conclusion.

## Cara Menjalankan Dashboard
1. Pastikan library terinstall: `pip install pandas matplotlib seaborn streamlit`
2. Masuk ke folder dashboard: `cd dashboard`
3. Jalankan aplikasi: `streamlit run dashboard.py`
